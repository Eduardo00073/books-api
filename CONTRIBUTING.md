# Guia de Contribuicao

Obrigado por se interessar pelo books-api, uma API REST em Spring Boot para gestao de livros e categorias com autenticacao JWT.

## Como contribuir

1. Faca um fork do repositorio.
2. Crie uma branch descritiva para sua alteracao.
3. Envie um Pull Request explicando o que foi mudado e por que.

## Sugestoes de contribuicao

- Novos endpoints ou melhorias nos existentes.
- Testes automatizados para os controllers e services.
- Melhorias na documentacao da API.

Toda contribuicao construtiva e bem-vinda!
